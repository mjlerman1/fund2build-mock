# Fund2Build clickable HTML mock

Static spec demo of the Fund2Build product UI. It is not a production app: **no payments**, **no Cursor SDK**, no backend.

## Open locally

From this folder:

1. Double-click `index.html`, or
2. Serve the folder with any static file server, for example:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080/

`index.html` is the Get started screen. The populated Trending feed is `trending.html`.

Relative links (`css/`, `js/`, `project/`, `studio/`) assume you start from this directory. Screen map: `screens.html`.

Reviewer files: `fund2build-get-started.mp4` (plays on Get started) and `../media/fund2build-reviewer-demo.mp4` (shareable click-through).
