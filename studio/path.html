Will you also run it for people?

Every project ships public source. The question is whether you commit to operate an instance and sell seats.

Open source

Public good

Pledges pay the factory. After ship, anyone can use, fork, or self-host. No instance promised, no perks. If it needs an API, users bring their own keys.

Hosted

You run it too

Same public source. You commit to an official instance, declare ongoing cost, and set backer seat tiers (a year free, a discount). Anyone may still self-host.
